## 既存のしくみ（これを使い、作り直さない）

- 敵: `ETYPES`（基本値と `ai`・`from`・`w`）→ `makeEnemy(type, x, y, f, elite)` → `spawnFloorEnemies(f)` で配置
- 敵の行動: `updateEnemies(dt)` の `switch (e.ai)`。補助に `step` / `contact` / `enemyShot` / `circleHazard`（予告円。`delay` 後に範囲内ならダメージ）/ `hazards`（`k:'line'` は予告線）
- 主: `BOSSES` → `makeBoss(f, x, y)`。行動は `updateBoss` / `bossNextPattern`（技の順番）/ `bossSeq`（時刻つきの手順）/ `bossAim`（予告線つき突進）
- 倒した処理: `killEnemy(e)`（経験値・欠片・ドロップ）。HP を 0 にして `killEnemy` を呼ばなければ報酬なしで消える（毎フレーム `enemies` から HP 0 が取り除かれる）
- 描画: `drawEnemy(e, t)` が `e.type` ごとに図形で描く。床と壁は `drawTiles()`（`FLOORC` と壁の色の直書き）
- 成長式 `hpMul` / `dmgMul` / `xpMul` は変えない

## やること

### 1. 区画のしくみ

- 区画は3つ: 1〜10階「崩れた坑道」、11〜20階「水没した聖堂」、21〜30階「灯の奥底」。31階から下は3区画の敵がすべて混ざる
- `ETYPES` の各敵に `zone`（1〜3）を足す。今ある5体（slime / bat / ghoul / caster / brute）は区画1
- `spawnFloorEnemies` は「その階の区画の敵のうち `from` 以下の階に達したもの」から抽選する。31階からは全区画の敵（`from` は無視）
- **区画2・3の敵はまだ無い**（2・3回目で作る）。それまでは、敵がいない区画では区画1の敵で代用する（空の抽選表にならないように）
- 床と壁の色を区画ごとに変える。`drawTiles` の直書きの色を区画ごとのパレットにする:
  - 坑道: 煤けた茶灰（床 `#1d1915` `#201b17` `#1a1612` `#221d18`、壁の上面 `#2e2620`、壁の前面 `#17120e`、縁 `#45382c`）
  - 聖堂: 青緑と緑青（床 `#12201f` `#142423` `#101c1b` `#162726`、上面 `#1f3331`、前面 `#0c1716`、縁 `#2f4d48`）
  - 奥底: 黒紫と赤い縁（床 `#1a1020` `#1d1224` `#170d1c` `#201427`、上面 `#2a1830`、前面 `#120914`、縁 `#4a2238`）
  - 31階からは 坑道→聖堂→奥底 を10階ごとに繰り返す
- HUD の階表示 `地下 N階` の横の小さい文字（今は「残り N体」）は変えなくてよい。区画が変わる階（1・11・21・31階…）に入ったときのバナーの2行目に区画名を出す（例「水没した聖堂」）

### 2. 主を6体の順に

- `BOSSES` を6体にする。順番と階: 5階 岩殻の王 ドルグ（golem）、10階 灯喰いの母 ネルヴァ（mother）、15階 沈鐘の巨蟹（crab）、20階 溺れた大司教（archbishop）、25階 堕ちた灯守り（fallen）、30階 灯を呑むもの（dark）
- 31階からは同じ順で繰り返し、6体ひと回りごとに強くする（今の `loop` の考え方を6体単位に）
- 巨蟹・大司教・灯を呑むものの動きと絵は2・3回目で作る。**今回は仮に**、巨蟹=ドルグの技、大司教=ネルヴァの技、灯を呑むもの=堕ちた灯守りの技を使わせ、絵も同じものを色違い（巨蟹は青緑、大司教は白と青、灯を呑むものは黒と赤）で描く。基本値: 巨蟹 r50・HP1000・攻撃26・速さ80・経験値150、大司教 r36・HP900・攻撃22・速さ90・経験値160、灯を呑むもの r56・HP1300・攻撃28・速さ60・経験値200
- 主の部屋は区画の床・壁の色で描かれること

### 3. 新しい敵「火薬虫」（`beetle`、区画1、6階から）

- 基本値: r13・HP16・攻撃22（自爆のダメージ）・速さ125・経験値5・出現の重み 20
- 動き: 速く近づく。プレイヤーとの距離が 70px 以内になったら止まって膨らみ始める（0.9秒）。膨らみ始めた瞬間に、自分の位置へ半径80の予告円（`circleHazard`、0.9秒後にダメージ `e.dmg`）を出す
- 0.9秒たったら自爆して消える（HP を 0 に。**`killEnemy` は呼ばず報酬なし**）。爆発の見た目は `burst` などで橙の破片を散らす
- 膨らみ終わる前にプレイヤーが倒したら、普通に `killEnemy`（報酬あり）で、爆発しない。そのとき出ている予告円も消す
- 図形の仮の絵: 黒い甲殻に赤い斑点の小さな甲虫、背中に茶色い火薬袋と火花の出る導火線（ART_SPEC の 06）。膨らみ中は体を大きく描き、赤く点滅させる

## 自分で確かめてほしいこと

- `<script>` ごとに構文エラーがない（例: Node で各 `<script>` の中身を取り出して `node --check`）
- 区画ごとの抽選表が空にならない（1〜40階をループして確かめる簡単なスクリプトでよい）
- 主の順番（5・10・…・30・35・40階）が上の表どおり

ブラウザでの自動プレイと画面の確認は、push のあとに Claude 側で行います。問題があれば Claude が直しの依頼（`task-01b.md` のような名前）を push します。
