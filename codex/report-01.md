# task-01 報告

## 変更したこと

- `ZONES`、`zoneForFloor`、`floorEnemyTypes` を追加し、区画ごとの敵の抽選、床・壁の配色、開始バナーを実装した。抽選できる敵がいない区画では区画1の敵で代用し、31階以降は全区画の敵を混ぜる。
- `BOSSES` と `makeBoss` を6体の順番と周回補正に対応させた。巨蟹・大司教・灯を呑むものには既存の技と図形を使い、`drawEnemy` で色を分けた。
- `ETYPES`、`updateEnemies`、`drawEnemy` に火薬虫を追加した。`circleHazard` と自爆のタイミングを揃え、先に倒したときは `killEnemy` で予告円を取り消す。

## 確認したこと

- `node --check` で HTML 内の全6スクリプトを確認し、構文エラーはなかった。
- Node で地下1〜40階を生成し、抽選表が空にならないこと、火薬虫が6階から抽選に入ること、5階刻みで主が ドルグ → ネルヴァ → 巨蟹 → 大司教 → 堕ちた灯守り → 灯を呑むもの → ドルグ → ネルヴァ の順に出ることを確認した。
- 区画名、主の部屋を含む床・壁の配色、31階以降の混成と周回補正を確認した。火薬虫は70pxで予告を始め、0.9秒で自爆した。自爆時は報酬がなく、先に倒したときは報酬が入り、予告円が消えて爆発も起きなかった。
